# Frontend

Interface web do AETHER AI, desenvolvida com React, TypeScript, Vite, Tailwind
CSS, React Router e Lucide React.

## Executar localmente

```powershell
npm install
npm run dev
```

O Vite informa o endereço local no terminal, normalmente
`http://localhost:5173`.

## Verificar

```powershell
npm run lint
npm run build
```

O dashboard e a navegação estão prontos para desenvolvimento. Conversas,
documentos, tarefas e configurações ainda não estão ligadas a uma API. O chat
mostra um aviso claro e não simula respostas quando a integração de IA está
indisponível.
